# Decisions

- Single-person execution; static site (Vite + React + TypeScript), no backend. Ranker runs in the browser.
- The pipeline is Node (`pipeline/fetch.mjs`, `tables.mjs`, `build_data.mjs`) instead of the Python scripts in PLAN.md. It started as one script with hand-copied values because PSI was reachable only from a browser; since R04 (2026-11-14) it downloads and parses the PSI files itself and the raw snapshot is committed in `pipeline/raw/`. See DATA_CLEANING_LOG.md.
- PSI record text is not copied into the app. The app shows short summaries and links to the PSI record. Publication lists are shown as counts with a link.
- Fire-safety roles follow the challenge statement grouping. Secondary role "suppression" is given to BASS and BASS-II (extinguishing-agent objective and title) and FLEX-2 (flame extinction objective). SPICE and SAFFIRE-I have no secondary role.
- ACME BRE is classed as prevention with fuel class gas: it emulates solid and liquid burning with a gas burner.
- Environment presets: lunar habitat, rover and spacesuit values come from the challenge statement. The Mars habitat atmosphere is our assumption. Station values cite the PSI-20 objectives text.
- Tailwind was not used; one plain CSS file.
- Earth applications and history links are a section of the "Method and sources" page instead of a separate page.
- Shareable links: the selection is stored after the # in the address (env, task, w, c, cmp). The address always follows the on-screen state, so editing it in an open tab has no effect; open the link in a new tab.
- Accessibility: skip link, labeled button groups, status text next to every icon, live announcement when the ranking changes, details panel as a dialog with focus handling, and a data-table alternative to the chart.
- Missing data in the ranking (R02, 2026-11-14): a factor the environment sets but the investigation did not record counts as untested (distance 1, the maximum), not skipped. Skipping it rescaled the weights and let studies with missing data outrank studies that recorded the value (spacesuit: BASS and SAFFIRE-III first with no O2 recorded). A midpoint of 0.5 was tried and still put the sealed-chamber ACME studies with nothing recorded first for the 100% O2 spacesuit. A factor the environment does not set (airflow on most presets) is still skipped for every investigation. To keep cabin-air experiments from being penalized for a missing column, cabin O2 (21%) is assumed for them, like cabin pressure (see DATA_CLEANING_LOG.md).
- AI layer (R06, 2026-11-14): AI writes briefs, Q&A answers and related-study reasons at build time only, from the computed rankings, gaps and checked findings (`pipeline/ai/context.md`). It never sets a score. "Ask the evidence" matches questions to the checked answers in the browser and generates nothing, so PLAN.md's "no live LLM chat" still holds; a bring-your-own-key free-form mode (R06c option 1) would change that and needs a team decision. Briefs exist for presets only (a custom environment's ranking cannot be checked in advance) and describe the default weights. The content was written with Claude Code in a development session; `pipeline/ai_build.mjs` checks every sentence. Findings now also quote PSI record text (objective, approach, hypothesis, research impacts) word for word, a narrow exception to "record text is not copied": only the quoted sentence, shown as the source of a finding.
